## Project Overview

This repository contains my completed **NumPy for AI/ML — Conceptual & Technical Assessment**, developed as part of Module 3.

The assessment explores the fundamentals of numerical computing using NumPy, with a focus on array manipulation, vectorized operations, mathematical computations, data preprocessing, and practical applications in artificial intelligence and machine learning.

The work is organized in a single, interactive Jupyter Notebook, combining conceptual explanations, code implementations, output interpretation, debugging exercises, and applied problem-solving.

## Objectives

* Understand and explain essential NumPy concepts and their relevance to AI/ML.
* Interpret array shapes, indexing, slicing, broadcasting, and aggregation results.
* Implement numerical solutions using vectorized NumPy operations.
* Identify and resolve errors in numerical and model-related code.
* Apply NumPy to data preprocessing, image batch handling, and simple modelling scenarios.

## Assessment Coverage

The notebook is organized into four required sections and one optional bonus section.

### Section A — Conceptual Understanding

Explores the core concepts and principles of NumPy, including:

* NumPy arrays compared with Python lists
* Vectorization and efficient numerical computation
* Element-wise multiplication versus matrix multiplication
* Broadcasting rules
* `flatten()` versus `ravel()`
* Array aggregation using `axis=0` and `axis=1`
* Normalization and standardization
* Handling missing values using `np.nanmean()`
* Representing batches of RGB images with multidimensional arrays
* Reproducibility using fixed random seeds

### Section B — Predict the Output

Focuses on logical reasoning and interpreting NumPy expressions, including:

* Broadcasting and resulting array shapes
* Array indexing and slicing
* Boolean indexing and filtering
* Matrix multiplication and transpose
* Mean calculations with missing values
* Conditional selection using `np.where()`
* Array dimensions and element counts
* Reverse slicing of multidimensional arrays

### Section C — Coding & Implementation

Implements vectorized solutions to numerical and AI/ML-oriented tasks:

* Pass/fail classification using `np.where()`
* Z-score standardization using a custom function
* Combining arrays using NumPy stacking operations
* Column-wise mean and standard deviation
* Linear model predictions using matrix multiplication
* Mean squared error (MSE) calculation
* Reproducible random data generation
* Min-max normalization of grayscale images
* Per-image average pixel calculations for RGB image batches

### Section D — Applied & Scenario-Based Problems

Applies NumPy concepts to practical data and modelling scenarios.

**D1. Data Preprocessing Pipeline**

* Detecting missing values
* Handling NaN values with an appropriate strategy
* Normalizing or standardizing the cleaned data

**D2. Image Batch Understanding**

* Understanding single-image and batch-image shapes
* Generating dummy RGB image data
* Calculating the element-wise average image across a batch

**D3. Debugging Model Code**

* Identifying dimensional incompatibilities
* Understanding matrix multiplication requirements
* Correcting mathematical expression errors
* Implementing the corrected prediction and MSE calculations

### Section E — Bonus & Challenge

Optional extra-credit exercises covering:

* Per-column min-max normalization of a feature matrix
* Three-level classification of examination scores using vectorized conditional operations
